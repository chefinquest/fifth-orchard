# Fifth Orchard

A mock e-commerce clothing brand website built as a white-pencil line-art / computer-blue blueprint storefront.

## What is in the site

- React + Vite + TypeScript single-page shop.
- Mock product data for six clothing/accessory pieces.
- Hand-drawn SVG clothing illustrations: coat, sweater, dress, satchel, trousers, scarf.
- Blueprint-blue background, white penciled line art, hand-drawn buttons inspired by the prior Pencil Button Canvas experiment.
- Working UI interactions:
  - category filtering
  - product spotlight on hover
  - mock add-to-cart satchel
  - clear cart
  - responsive layout

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

This repo includes a GitHub Pages workflow that builds `dist/` and deploys it as a project page.
